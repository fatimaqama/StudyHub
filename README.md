# StudyHub – Student Study Management System

StudyHub is a student productivity web application designed to help students organise their studies, manage tasks, track progress and keep their revision notes in one place.

## Features

- **Dashboard** – View study hours, completed tasks, deadlines and overall progress.
- **Subject Management** – Organise subjects using colour-coded cards and progress indicators.
- **Task Management** – Add, edit, delete, search and filter tasks by subject, priority and status.
- **Study Planner** – View weekly schedules and log study sessions.
- **Notes** – Create, edit, search and pin revision notes by subject.
- **Progress Tracking** – Monitor completed tasks, study hours and subject progress.
- **Settings** – Switch between light and dark themes, update profile details and manage demo data.

## Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage

## Project Status

StudyHub is a personal development project built to practise web development and create a practical study management tool. The main interface and core features have been developed, with further improvements possible.

The application currently stores its data in the browser's Local Storage rather than a connected database.

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `dashboard.html` in your browser, or use the Live Server extension.
4. Explore the different sections using the sidebar.
